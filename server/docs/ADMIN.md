# Administration – LCS v0.7

Die Weboberfläche zeigt registrierte Geräte, lokal ermittelte Basisinformationen,
Gruppen, Enrollment-Tokens und Ausführungsprotokolle. Unter **Aufgaben** steht
eine schreibgeschützte Liste der Fähigkeiten, die Clients tatsächlich gemeldet
haben. Nur eine auf jedem gewählten Ziel vorhandene Fähigkeit kann angefordert
werden. Einen Editor, Upload oder Download von Client-Code gibt es nicht.
