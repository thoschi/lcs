# Installation – LCS v0.7

Linux: `./install.sh install server` beziehungsweise
`./install.sh install workstation https://lcs.example`.

Windows: `./install.ps1 install server` beziehungsweise
`./install.ps1 install workstation https://lcs.example` in einer administrativen
PowerShell. `upgrade` aktualisiert eine bestehende Installation unter Erhalt von
Konfiguration, Geräteidentität und lokalen Nutzerinformationen.
